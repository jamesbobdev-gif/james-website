# James Fartro's website

A personal site: a home page and a projects page, with pixel rain in the background.
Plain HTML, CSS and JavaScript, with no build step.

- `index.html`: home page
- `projects/index.html`: projects page
- `404.html`: page-not-found page
- `style.css`: styles for every page
- `script.js`: the rain animation, the footer year, and the résumé request button
- `publish.ps1`: optional deploy to Cloudflare Pages

Hosted with GitHub Pages from the `main` branch at https://jamesfartro.com.
